# Grazioso Project Two

This project was completed as part of SNHU IT-145.

## Description
This Java application simulates a system used by Grazioso Salvare to manage and track rescue animals. The program allows users to add, view, and manage different types of rescue animals, including dogs and monkeys.

## Features
- Add new rescue animals
- Store and manage animal information
- Display lists of animals
- Support for multiple animal types (Dog and Monkey)
- Menu-driven user interaction

## Concepts Demonstrated
- Object-Oriented Programming (OOP)
- Inheritance (Dog and Monkey extend RescueAnimal)
- Encapsulation
- Arrays / ArrayLists
- Control structures (loops, conditionals)
